## Decisions this plan adds to the spec

- **Outside cones run in order along the arc, between the inside cones** (sorted by how far along the arc each is), not all after them as the spec's "after its inside cones" says: the route line then follows the turn instead of doubling back. With Outside cones off the order is exactly today's.
- **Outside cones are spaced along the outer edge itself** (the edge is sampled, not the centreline), so the gaps on the lot are the ones the table gives.
- **`touchUps` is `{ placed, cones }`.** `placed` is how many cones Place cones put down when the list was frozen; `cones` are `{ type, x, y, heading, element, edited }` in canvas metres, headings clockwise on screen like elements. The "changes" count shown in the Cones box and the clear question is worked out, not stored: deleted cones (`placed` minus the cones still carrying an element id) plus cones marked `edited` (moved, retyped, turned, added). Moving one cone twice is one change.
- **A touch-up that changes nothing** (Make standing on a standing cone) records no step and does not freeze or lock the track.
- **The lock lives in `Commands.run`:** while `touchUps` exists, only `newTrack`, `setPhoto`, the five touch-up commands and `clearTouchUps` run (`Commands.WHILE_LOCKED`); every other command returns the track unchanged. `Commands.COMMAND_NAMES` lists every command, so a test catches a future command that forgets to say whether it runs while locked.
- **Cones are picked by their position in the placed list** (`TrackStore.coneSelection`, indices into `preview.canvasCones`). The selection is dropped when the cones are hidden, the preview is cleared, the track is replaced, or the number of touched-up cones changes (a delete, an add, undoing past the first touch-up). The nearest cone within its footprint plus 4 screen pixels is picked: half of 10.5 in for a standing cone, half of 18 in for a leaning one.
- **A drag on a cone moves only that cone;** a plain click on one of several selected cones selects it alone (as for elements).
- **The density slider** is labelled at its two ends (Fewest, Most) with the current notch named under it (five full names do not fit the 280-pixel panel). A mouse drag along it is one undo step; each arrow-key step is its own.
- **The per-element drop-down** lists "Same as track", Fewest … Most; the closed box reads "Same as track (SAE standard)", naming the track's notch.
- **Tools › Car outline is greyed until the ruler has a length** (the outline needs a scale), and the outline hides if the scale goes. The car's rotate handle sits 24 screen pixels beyond its nose. The picture's top is the car's front.
- **A `.cone` whose `touchUps` sits on a design that cannot be processed** (no Direction target, no elements) is refused as damaged: it could otherwise open locked with no cones to show.
- **Hand-edited joins slightly apart (minor 6)** are glued only when some joint is apart (more than 1 µm): a file the app saved itself opens with its positions untouched.

Create `app/qml/logic/density.mjs`:

```js
// Cone density: five notches that scale the largest gap between cones. Notch 3, "SAE standard", is the spacing the app
// has always used (it meets the SCCA course-design guidance; the FSAE rules give no spacing). A track has one notch; an
// element may have its own. Slalom apex cones and lines keep their own spacing settings. Tests: tests/qml/tst_density.qml.
export const NOTCHES = [1, 2, 3, 4, 5]
export const NAMES = { 1: "Fewest", 2: "Fewer", 3: "SAE standard", 4: "More", 5: "Most" }
export const FACTORS = { 1: 2, 2: 1.5, 3: 1, 4: 0.75, 5: 0.5 }
export const STANDARD = 3

// The track's notch: its own when it is one of the five, otherwise SAE standard (a track from before part 4).
export function trackNotch(track) {
    return NOTCHES.indexOf(track.density) >= 0 ? track.density : STANDARD
}

// An element's notch: its own Cone density setting when it has one (1 to 5), otherwise the track's (0 or none).
export function elementNotch(el, trackNotch) {
    const own = el.props ? el.props.density : 0
    return NOTCHES.indexOf(own) >= 0 ? own : trackNotch
}

// What a notch multiplies the largest gap by.
export function factor(notch) {
    return FACTORS[notch] || 1
}
```

```js
// Touch-ups: hand changes to placed cones before the track is saved or uploaded (delete, move, standing or leaning, where
// a leaning cone points, add). They belong to one round of Place cones. The first touch-up freezes the placed cones into
// the track as `touchUps`; while it exists the track is locked (commands.mjs) so the list never has to be matched to a
// changed track. touchUps = { placed, cones: [{ type, x, y, heading, element, edited }] }: `placed` is how many cones
// were frozen; positions in canvas metres and headings clockwise on screen, like elements. Tests:
// tests/qml/tst_touchups.qml.
import * as Frame from "./frame.mjs"
import * as Post from "./postprocess.mjs"

// Half a cone's footprint: a standing cone's base is 10.5 in across; a leaning cone is 18 in long.
export const STANDING_RADIUS = 10.5 / 2 * 0.0254
export const LEANING_RADIUS = 18 / 2 * 0.0254

export function radius(cone) {
    return cone.type === "leaning" ? LEANING_RADIUS : STANDING_RADIUS
}

function copy(c) {
    return { type: c.type, x: c.x, y: c.y, heading: c.heading, element: c.element, edited: c.edited === true }
}

// The placed cones as touch-ups start from, or null when the track cannot be processed.
export function freeze(track) {
    const result = Post.run(track)
    if (result.error)
        return null
    return { placed: result.canvasCones.length, cones: result.canvasCones.map(copy) }
}

function valid(u, indices) {
    return indices.filter(i => i >= 0 && i < u.cones.length)
}

// Each change returns new touch-ups and leaves `u` as it was. `indices` are positions in u.cones.
export function removeCones(u, indices) {
    const gone = valid(u, indices)
    return { placed: u.placed, cones: u.cones.filter((c, i) => gone.indexOf(i) < 0).map(copy) }
}

function changed(u, indices, change) {
    const which = valid(u, indices)
    return { placed: u.placed,
             cones: u.cones.map((c, i) => which.indexOf(i) < 0 ? copy(c) : Object.assign(copy(c), change, { edited: true })) }
}

export function moveCone(u, index, x, y) {
    return changed(u, [index], { x: x, y: y })
}

// Only cones of the other type change; a cone made leaning keeps its heading.
export function setType(u, indices, type) {
    return changed(u, valid(u, indices).filter(i => u.cones[i].type !== type), { type: type })
}

export function pointCone(u, index, heading) {
    return changed(u, [index], { heading: heading })
}

// A standing cone added by hand, after every other cone in the driving order.
export function addCone(u, x, y) {
    return { placed: u.placed,
             cones: u.cones.map(copy).concat([{ type: "standing", x: x, y: y, heading: 0, element: null, edited: true }]) }
}

// How many changes the touch-ups hold: cones deleted, plus cones moved, retyped, turned or added (0 for none).
export function changes(u) {
    if (!u)
        return 0
    const kept = u.cones.filter(c => c.element !== null).length
    return (u.placed - kept) + u.cones.filter(c => c.edited).length
}

// The nearest cone whose footprint, grown by `extra` metres, covers p (canvas metres); -1 when none does.
export function coneAt(cones, p, extra) {
    let best = -1
    let bestDistance = Infinity
    cones.forEach((c, i) => {
        const d = Math.hypot(c.x - p.x, c.y - p.y)
        if (d <= radius(c) + extra && d < bestDistance) {
            best = i
            bestDistance = d
        }
    })
    return best
}

// The cones inside a box (corners in canvas metres, either way round).
export function inBox(cones, a, b) {
    const x0 = Math.min(a.x, b.x), x1 = Math.max(a.x, b.x), y0 = Math.min(a.y, b.y), y1 = Math.max(a.y, b.y)
    const out = []
    cones.forEach((c, i) => {
        if (c.x >= x0 && c.x <= x1 && c.y >= y0 && c.y <= y1)
            out.push(i)
    })
    return out
}

// What Place cones shows and the file holds while touched up, in Post.run's shape: { cones (export frame),
// canvasCones, targetDistance }, each cone with its index and `edited`; or { error } when the track cannot be processed.
export function result(track) {
    const error = Post.check(track)
    if (error)
        return { error: error }
    const frame = Frame.makeFrame(track.targets.origin, track.targets.direction, track.photo.metresPerPixel)
    const canvasCones = track.touchUps.cones.map((c, index) => Object.assign({ index: index }, copy(c)))
    const cones = canvasCones.map(c => {
        const q = Frame.toFrame(frame, c)
        return { index: c.index, type: c.type, x: q.x, y: q.y, heading: Frame.headingToFrame(frame, c.heading),
                 element: c.element, edited: c.edited }
    })
    return { cones: cones, canvasCones: canvasCones, targetDistance: frame.distance }
}
```

```js
// A cone of a touched-up list, or null when it cannot be read.
function readCone(v) {
    if (!isObject(v) || ["standing", "leaning"].indexOf(v.type) < 0 || !isNumber(v.x) || !isNumber(v.y) || !isNumber(v.heading))
        return null
    if (v.element !== null && typeof v.element !== "string")
        return null
    return { type: v.type, x: v.x, y: v.y, heading: v.heading, element: v.element, edited: v.edited === true }
}

// The design's touch-ups ({ placed, cones }), or null when they cannot be read.
function readTouchUps(v) {
    if (!isObject(v) || !Array.isArray(v.cones) || !isNumber(v.placed))
        return null
    const cones = []
    for (const c of v.cones) {
        const cone = readCone(c)
        if (!cone)
            return null
        cones.push(cone)
    }
    return { placed: Math.max(0, Math.round(v.placed)), cones: cones }
}

// Joined ends a hand edit has left slightly apart (up to JOIN_SLACK, see repairJoins) are glued exactly, so the next
// edit does not quietly unjoin them. A file the app saved itself has every joint together and is left untouched.
function glueNearJoins(elements) {
    const apart = elements.some(el => ["A", "B"].some(end => {
        const j = el.joins[end]
        if (!j)
            return false
        const a = Elements.endsWorld(el)[end]
        const b = Elements.endsWorld(elements.find(e => e.id === j.id))[j.end]
        return Math.hypot(a.x - b.x, a.y - b.y) >= 1e-6
    }))
    if (apart) {
        Snapping.glueAll(elements)
        Snapping.unjoinApart(elements)
    }
}
```

```js
// The true-size car outline (Tools › Car outline): a rectangle `length` long and `width` wide in canvas metres, centred
// on car.x, car.y, its front along car.rotation (degrees clockwise on screen, like elements). It is never part of the
// track. Tests: tests/qml/tst_car.qml.

function local(car, p) {
    const r = -car.rotation * Math.PI / 180
    const dx = p.x - car.x
    const dy = p.y - car.y
    return { x: dx * Math.cos(r) - dy * Math.sin(r), y: dx * Math.sin(r) + dy * Math.cos(r) }
}

function world(car, q) {
    const r = car.rotation * Math.PI / 180
    return { x: car.x + q.x * Math.cos(r) - q.y * Math.sin(r), y: car.y + q.x * Math.sin(r) + q.y * Math.cos(r) }
}

// Whether p (canvas metres) is on the car.
export function contains(car, length, width, p) {
    const q = local(car, p)
    return Math.abs(q.x) <= length / 2 && Math.abs(q.y) <= width / 2
}

// The four corners, front left first, going round.
export function corners(car, length, width) {
    return [{ x: length / 2, y: -width / 2 }, { x: length / 2, y: width / 2 }, { x: -length / 2, y: width / 2 },
            { x: -length / 2, y: -width / 2 }].map(q => world(car, q))
}

// The rotate handle, `extra` metres past the nose.
export function handle(car, length, extra) {
    return world(car, { x: length / 2 + extra, y: 0 })
}

// The rotation that points the car's front at p; in `step`-degree steps when step > 0 (Shift).
export function facing(car, p, step) {
    let r = Math.atan2(p.y - car.y, p.x - car.x) * 180 / Math.PI
    if (step > 0)
        r = Math.round(r / step) * step
    return r
}
```
